# Pellet firmware v2.0.0

Release date: 2026-08-13

Source tag: `v2.0.0`<br>
Source commit: `3c0d93e6bb53dc4d0adbf21c213ded72a9b0e2ff`

## Changes

- Assert pellet-board `STIM0` for the complete 5 kHz Tone 1 interval.
- Assert pellet-board `STIM1` for the complete 6 kHz Tone 2 interval.
- Clear both automatic tone markers for other frequencies, completion, abort,
  and tone-start failures.
- Leave `STIM2` and `STIM3` without automatic tone assignments.
- Preserve the original upstream repository history and attribution in the
  Cerebellum Lab fork.

## Acceptance criteria

- Firmware version request reports `2.0.0` after reboot and finalization.
- No tone: `STIM0=0`, `STIM1=0`.
- 5 kHz Tone 1: `STIM0=1`, `STIM1=0` for the tone interval.
- 6 kHz Tone 2: `STIM0=0`, `STIM1=1` for the tone interval.
- Any other tone frequency: `STIM0=0`, `STIM1=0`.
